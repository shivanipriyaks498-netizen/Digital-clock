# Digital Clock

A simple and interactive Digital Clock built using React.js, JavaScript, and CSS.

## Features
- Real-time digital clock
- Dynamic time updates
- Responsive user interface
- Clean and simple design

## Technologies Used
- React.js
- JavaScript
- CSS3
- Vite

## Run Locally

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev
